# 雀魂牌局观察器：核对原型

Edge Manifest V3 扩展。只在 `https://game.maj-soul.com/*` 页面运行，无外部依赖，无后台服务、遥测或外发接口。当前版本为 **0.1.4**，协议字段尚待当前客户端实测。

手牌、牌河、副露、宝牌及事件列表使用本地牌面图片，包含34种常规牌与3种赤五；悬停可看牌名。未知牌显示问号，避免与白板混淆。图片随扩展打包，不向外部图床请求。

手牌按万、筒、索、字牌及点数排序，赤五紧邻普通五；收到摸牌动作后，刚摸的牌单独放在右侧，弃牌后重新理牌。排序仅影响显示，导出保留采集顺序。游戏内手动拖牌、关闭自动理牌时，排列可能与面板不同。

面板顶部以红框显示“对手立直”，自家立直不触发此提示，多家立直会合并显示；本局结束或新局开始时清除。实时模式使用已识别或手动指定的自家座位；牌谱模式需先选择“自家”座风，提示跟随插件游标，未选时不猜测自家身份。

自家座位自动识别或手动选定后，“尚未识别”警告立即更新；若识别前已存在未追踪的动作，则提示历史手牌变化不完整，直到下一局完整开局重置。识别座位不会自动补回此前遗漏的手牌动作。

## 安装与首次核对

1. 在 Edge 地址栏打开 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择 `D:\雀魂插件\extension` 文件夹。
3. 刷新雀魂页面，让采集器在游戏连接建立前加载；刷新会离开当前回放位置。
4. 重新打开牌谱，右上角应出现“牌局观察器”。可收起面板腾出画面。
5. 若成功捕获牌谱，面板自动切换到“牌谱记录”，显示四家手牌。面板的牌谱游标**独立于游戏**，通过“上一事件 / 下一事件”手动与画面对齐；当前不自动跟随游戏播放。
6. 按当前测试要求：保留你已设置的正常对局显示方式，点击游戏播放按钮后隐藏游戏工具栏，再核对。工具栏隐藏不会改变网络采集逻辑。
7. 若只看到“实时消息”，展开“采集状态”，检查连接数、接收帧、错误提示。可在练习局从开局采集增量事件。牌谱播放不一定产生实时动作消息，不能仅以画面变化判断采集器失效。
8. “导出核对记录”下载本地 JSON；可用它报告某个动作不一致的问题。

浏览器已有连接与已经下载的牌谱无法被本原型追溯读取，因此首次安装后必须刷新并重新打开。源码变更后，在扩展管理页点“重新加载”，再刷新雀魂页面。

## 核对顺序

- 开局：场风、局数、本场、立直棒、点数、剩余牌数、宝牌指示牌、手牌。
- 动作：摸牌、弃牌、摸切/手切、立直声明与成功扣点、吃碰杠、被鸣牌的弃牌。
- 牌谱牌河中的灰色牌仍按消息里的牌种读取；灰色本身不作为摸切、立直或被鸣牌的判断依据。面板分别显示“摸切 / 手切 / 立直 / 已鸣”文字。若后续增加视觉采集，须单独验证灰色牌，不得将它当作背景丢弃。
- 结算：和牌/流局及点数。
- 面板以东、南、西、北显示本局座风，随庄家轮转，并非固定屏幕方位；实时自家座位优先根据操作提示识别，也可手动选择。开局信息未获得时显示“座风待定”。事件历史保留事件发生时的座风，导出仍保留协议座位编号以便调试。未识别前，手牌增量可能不完整。
- 记录“游戏画面上的动作、面板事件编号、期望值、实际值”。若不一致，导出 JSON 即可，不需提供账号登录数据。

## 已实现与限制

- 浏览器原生 WebSocket 旁路观察；不新增游戏请求，不修改消息内容，不调用游戏出牌接口。
- 仅解码明确选取的牌局消息；登录、心跳、聊天等内容不保留。请求响应关联只保留方法名和消息序号。
- 支持 Liqi 动作混淆与明文兼容尝试，手写最小 Protobuf wire reader，无第三方运行库。
- 支持 `ActionPrototype` 中的常规开局、摸打、吃碰杠、拔北、立直成功与常规结算。
- 支持 `fetchGameRecord` 内嵌数据以及游戏随后经 fetch/XHR 下载的指定牌谱 URL。不会主动下载。支持 `GameDetailRecords.records` 与 `actions.result`。
- 仅保留规范化牌局字段，不导出账号、会话、令牌、原始二进制、下载URL或牌山。
- 断线快照暂不支持完整重建；会提示重新从开局采集。动作缺口及未知动作会标记状态不完整。
- 当前协议来自已有公开资料，必须在当前 Unity 客户端验证。特殊规则、跨版本协议、压缩/其他牌谱封装尚未适配。
- 自家手牌、牌河、副露为事件状态机推导，尚无真实对局正确率保证。最近动作座位不等于准确的下一位出牌者。
- 牌谱四家手牌仅用于复盘，不代表实时对局能读取对手暗牌。面板独立游标与游戏隐藏工具栏均不改变此边界。
- 页面内桥接消息可被同页脚本伪造，不应作为可信审计来源；本扩展不暴露浏览器特权能力。
- 导出最多最近1000条实时事件、最近60条诊断，牌谱上限25000条/16MiB；超限会停止对应解码并提示。

测试使用人工构造的协议帧与模拟 WebSocket，不连接账号、不进行游戏操作。`tests/preview.html` 是显式标注的离线界面演示，不能作为真实采集成功的证据。
