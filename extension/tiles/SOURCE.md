# 牌面资源

本目录的37张SVG由本项目的 `scripts/generate-tiles.mjs` 生成，采用自行编排的几何图形、数字和通用汉字，覆盖34种常规牌与3种赤五，按项目MIT许可证分发。它们不是雀魂截图，也没有使用游戏纹理、角色、商标或第三方牌面素材。

SVG使用浏览器可用的 `sans-serif` 字体显示通用汉字，没有捆绑或下载字体文件。不同系统上的字形可能略有不同。白板使用空心方框，未知牌由面板另行显示问号。

重新生成：在仓库根目录运行 `npm run tiles`；校验生成结果运行 `npm run check`。

早期提交已在公开前迁移为本项目原创SVG，并同步修改资源引用；原截图牌面、旧安装包和研究文件已从公开提交历史移除。旧素材不属于本项目MIT授权范围。
