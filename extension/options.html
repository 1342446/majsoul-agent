分析服务设置

默认关闭外部分析。可配置 OpenAI Chat Completions 服务，或选用本地 mjai 适配。开启后，在牌局面板选择数据并点击分析才会发送；每次聊天模型调用可能产生服务商费用。

聊天模型提供局面分析与解释。

支持 HTTPS 服务，以及 HTTP 的 localhost / 127.0.0.1 本地服务。保存时仅申请该服务地址的访问权限。

密钥保存在当前浏览器的扩展本地存储，不参与同步、局面导出或页面桥接。发送的数据由你配置的服务商处理。

牌局信息、牌河和自家手牌可分别选择；即使复盘时插件持有四家手牌，也只发送所选自家手牌。模型结果仅供参考。
